# Natural Language Processing

Course notes based on Tianxing He's Natural Language Processing lectures at Tsinghua University's Institute for Interdisciplinary Information Sciences (IIIS).

## Course outline

1. [Part 1 · Classical NLP](part-1/index.md) covers grammars, statistical models, and word representations.
2. **Part 2 · LLM Extensions and Systems** will cover language generation, reasoning, and efficient training and serving.
3. **Part 3 · Multimodality, Evaluation, and Agents** will cover vision-language models, generated-text detection, evaluation, and agents.
